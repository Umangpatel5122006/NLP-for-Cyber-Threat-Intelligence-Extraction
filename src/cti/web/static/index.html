      ABOUT THIS WORKSPACE
      
    
      Traceable findings.
      Classical methods.
      Entity and action tagging uses saved CRFs. Short English messages (up to 1,000 characters) also use a word/character TF-IDF linear classifier trained on SMS ham/spam labels. Indicators and scam patterns use rules. Both workbench modes include the available SMS model; IOC mode skips the entity/action models.
      One Findings list, distinct evidence
      The Findings list includes extracted entities/IOCs, message-rule detections and positive SMS-model predictions. Each row identifies its method and source evidence. Model predictions and rules can disagree; a ham prediction does not erase suspicious rule evidence. The message assessment shows both outcomes.
      Read the sources, not a combined score
      No combined attack probability is created. A linear decision margin is not a probability. SMS spam is not verified fraud; the model can miss unfamiliar scams. NER confidence is unavailable. No identity or phone/domain reputation lookup is performed.
      Highlights follow the original report
      Cleaning and defanging happen for analysis. Highlights use original source-covering spans, including Unicode and defanged indicators. Host components, overlaps and message cues remain available for inspection.
      This is a research baseline. CTI extraction and SMS spam are separate tasks with separate evaluation results. No detections does not establish safety.
